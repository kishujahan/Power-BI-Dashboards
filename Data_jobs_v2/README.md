# Data Jobs Dashboard 2.0

## 📌 Introduction

Building upon the foundations of my initial Data Jobs analysis, Data Jobs Dashboard 2.0 represents a significant technical leap in my Power BI journey. While the first version focused on core visualization and drill-through reporting, this iteration emphasizes dynamic user interaction and advanced data modeling.

This dashboard follows the architectural framework designed by [Luke Barousse](https://youtu.be/FwjaHCVNBWA?si=CW3iSXzXALXmF9UR). While the core metrics and parameters align with the tutorial, the development process involved significant independent troubleshooting, particularly in interface optimization, layer management, and precision formatting to ensure a production-ready finish


## 🧠 Skills Showcased


### Dynamic Data Exploration (Field Parameters):

- Implemented Field Parameters to allow users to dynamically toggle between different dimensions and measures within the same visual.

- Reduced dashboard clutter by consolidating multiple views into a single, user-driven interactive chart.

### Advanced DAX Logic:

- Developed DAX measures to calculate Job Count, median yearly salary, and median hourly salary, and to show the relative share of each skill within the dataset, dynamically updating based on parameter selections.

### KPI Development & Tracking:

- Designed KPI cards to track essential metrics such as Job Count, Median Salary, and Hourly Rates.

- Integrated cards that automatically update based on Field Parameter selections, providing instant context for the filtered data view.

### Enhanced UI/UX Design (Dark Mode):

- Designed a sleek Dark Mode interface, prioritizing high-contrast data points and readability for long-term monitoring.

- Applied advanced formatting to ensure consistency across custom buttons, slicers, and background shapes.

### Sophisticated Interface Interactivity:

- Engineered a seamless navigation experience using a combination of Bookmarks, Selection Panes, and Buttons.

- Implemented custom reset buttons and toggles to improve the "app-like" feel of the dashboard.

This project demonstrates the application of advanced Power BI features to transform raw job market data into an interactive and insightful dashboard. It reflects an improvement from basic reporting to more advanced analytical capabilities.

Building this dashboard provided valuable opportunities to troubleshoot and resolve complex technical challenges independently. The end result is a high-performance analytical tool that provides deep job market insights while maintaining a seamless and intuitive user experience.
